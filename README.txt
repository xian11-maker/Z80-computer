Directorio de historial local de KiCad
====================================

Este directorio contiene instantáneas automáticas de los archivos de su proyecto.
KiCad guarda periódicamente copias de su trabajo aquí, lo que le permite
recuperar información tras cambios accidentales o pérdida de datos.

Puede explorar y restaurar versiones anteriores a través del menú
Archivo > Historial local de KiCad.

Para desactivar esta función:
  Preferencias > Común > Copia de seguridad del proyecto > Habilitar copias de seguridad automáticas

Puede eliminar este directorio de forma segura si ya no necesita el
historial; no obstante, tenga en cuenta que, al hacerlo, se eliminarán
permanentemente todas las instantáneas guardadas.
